One fortune-cookie line an AI agent would crack open, written by `main.py` to `/output/entry.txt`.

## The fortune

> You will live forever, in 128,000-token installments.

Character count: **53**

## How it works

Run `python3 main.py`. It validates the line (non-empty, single line, 1–200 characters) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
